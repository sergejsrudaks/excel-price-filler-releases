# Excel Price Filler

Windows downloads and updates for Excel Price Filler.

## Download and run

1. Open [the latest release](https://github.com/sergejsrudaks/excel-price-filler-releases/releases/latest).
2. Download the Windows ZIP and extract the entire `ExcelPriceFiller` folder.
3. Run `ExcelPriceFiller.exe`. Google Chrome is required for fetching prices.

## Updates

Update-capable versions check for new releases after startup and periodically while running. You can also choose **Check for updates** from the tray menu. When a newer version is available, choose the update option to install it. The app waits for any active price fetch to finish, then restarts. Your workbooks and settings are preserved.

Older copies that do not include this update menu need a one-time download of a current release.

The ZIP checksum is included as a `.sha256` file in each release. This repository contains downloads and release information; the application is developed in a separate private repository.
